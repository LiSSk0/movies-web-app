# Web application “Personal Movie Recommendations”
**Personal movie recommendations** — is a web application for selecting recommended movies based on user preferences.

## Technologies
- Backend: Python (Flask)
- Database: SQLite

## Main functions
- Personal recommendation system by AI (Content Based Filtering method)
- Database with more than 35.000 movies
- The ability to rate movies (0 to 10)
- Simple logging system through an email without password
- Plain profile page with your rated movies and top-10 recommendations

## Installation
**1. Clone the repository:**
```bash
git clone https://github.com/LiSSk0/movies-web-app.git
cd movies-web-app
```

**2. Download [Python](https://www.python.org/downloads/).**  
When installing, click the checkmark next to "add to PATH"

**3. Set up a virtual environment and install dependencies:**  
Go to the project folder.
Set up the Backend (Python):
```bash
cd backend
python -m venv venv  # creating a virtual environment
venv\Scripts\activate     # for Windows
source venv/bin/activate  # for macOS/Linux
pip install -r requirements.txt  # setting up the requirements
```

**4. Run the project:**
```bash
python backend/src/start.py
```
